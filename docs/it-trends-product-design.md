# 日本 IT 業界トレンド機能 产品设计

## 1. 产品概述

在现有的 React/TypeScript 个人履历网站中增加「最近のIT業界トレンドを見る」功能，展示来自 Hacker News、Zenn、Qiita 等来源的日本 IT 行业资讯。

系统对抓取到的内容进行统一整理，并使用 Gemini API 生成简短的日语摘要，帮助访问者快速了解近期值得关注的技术主题。

该功能作为履历网站的独立子页面存在，不影响原有履历浏览、访客计数和 RAG 问答功能。

## 2. 产品目标

- 丰富个人履历网站的内容和实用性。
- 展示对日本 IT 行业动态的持续关注。
- 通过真实数据体现数据抓取、AI 摘要和 Serverless 应用能力。
- 让访问者能够快速浏览近期技术趋势，而不需要逐篇阅读原文。

## 3. 目标用户

- 希望了解候选人技术关注方向的招聘人员。
- 对日本 IT 行业和技术社区感兴趣的访问者。
- 通过网站了解候选人实践能力的技术人员。

## 4. MVP 范围

### 4.1 首页入口

在履历首页增加一个明显的按钮：

> 最近のIT業界トレンドを見る

点击后进入同一网站内的 IT 趋势子页面。

### 4.2 趋势列表

每条趋势至少展示：

- 文章标题
- 来源名称
- 发布时间
- 日语摘要
- 技术分类或标签
- 原文链接

页面显示最近更新时间，并在没有数据或加载失败时提供明确提示。

### 4.3 数据来源

MVP 首先支持少量稳定来源，建议从以下来源中选择 2～3 个：

- Hacker News
- Zenn
- Qiita

GitHub Trending 和 ITmedia NEWS 作为后续扩展，不纳入首版验收范围。

### 4.4 AI 摘要

Gemini 仅用于对已抓取的文章进行轻量处理：

- 生成简短的日语摘要
- 提取或补充技术分类
- 生成少量关键词

摘要必须基于抓取到的标题、描述或正文内容，不应添加原文中不存在的事实。

## 5. 用户流程

```text
访问履历首页
    ↓
点击「最近のIT業界トレンドを見る」
    ↓
进入 IT 趋势页面
    ↓
浏览趋势卡片
    ↓
点击原文链接查看完整内容
```

## 6. 页面要求

- 延续现有履历网站的视觉风格。
- 桌面端和移动端均可正常浏览。
- 趋势卡片应突出标题和摘要，避免信息过载。
- 外部文章在新标签页打开。
- 页面应显示数据更新时间。
- 数据加载失败时不影响履历首页和其他功能。

MVP 可以使用简单的同站子路由或 hash 路由，例如：

```text
/#/trends
```

## 7. MVP 不包含的功能

- 用户登录和个性化推荐
- 收藏、评论和分享
- 复杂搜索和全文检索
- 后台管理界面
- 多轮 AI 对话
- 自动生成长篇文章
- 复杂的数据统计和趋势预测
- 一开始接入所有资讯来源

## 8. 数据与更新方向

前端统一读取标准化的趋势数据。MVP 可以先使用静态 `news.json` 验证页面，后续再接入定时处理流程：

```text
定时任务
    ↓
抓取资讯
    ↓
去重与统一格式
    ↓
调用 Gemini 生成摘要
    ↓
保存 news.json
    ↓
网站读取并展示
```

后续可使用 AWS Lambda、EventBridge 和 S3 实现自动更新。

## 9. 成功标准

- 用户可以从履历首页明确找到趋势功能入口。
- 用户可以进入独立的 IT 趋势页面。
- 页面可以展示多来源资讯及日语摘要。
- 每条资讯都能跳转到原文。
- 页面在手机和桌面端均可正常使用。
- 趋势功能异常时不影响履历主体、访客计数和 RAG 问答。

## 10. 后续方向

- 增加 GitHub Trending 和 ITmedia NEWS。
- 按 AI、Cloud、Web、Security 等分类筛选。
- 增加关键词搜索和日期筛选。
- 保存历史趋势数据。
- 增加热门主题、来源分布和时间趋势图表。
- 根据用户关注方向进行个性化推荐。
