# ポートフォリオの構成と更新

## ページ構成

- 履歴書トップ: 個人紹介 → 精選プロジェクト → 既存の履歴タイムライン → 自己 PR・実務経験 → 学歴・資格 → スキル → 連絡先。
- `#/projects`: 全プロジェクトの一覧と分野別フィルター。
- `#/projects/<id>`: 各プロジェクトの概要・機能・設計上の判断。
- `#/journey/<id>` と `#/trends`: 既存の経歴詳細・IT Trends を維持。

ハッシュによる画面切り替えを使い、S3 / CloudFront に新たなリライト設定を必要としません。`#projects` はトップの精選一覧、`#/projects` は全件一覧です。

## プロジェクトの追加

1. `src/data/projects.ts` の `projects` に一件追加します。`id` は既存と重複しない、小文字英数字とハイフンの固定値にします。
2. `featured: true` の先頭 4 件までがトップにも表示されます。一覧の順序は配列の順序です。
3. `category` に `ai` または `cloud` を設定します。分野を増やす場合は型と `projectCategories` を併せて更新します。
4. 画像は `public/images/` に置き、`coverImage: { src, alt }` と `gallery: [{ src, alt, caption }]` で指定します。画像なしでも概要のカバーを表示できます。
5. `overview`、`features`、`decisions` に公開可能な説明を書きます。数値や成果は確認できたものに限ります。
6. 公開可能な場合だけ `liveLink`、`repositoryLink`、`articleLink` を設定します。空欄のリンクは表示しません。
7. 経歴との関連は `journeyId` で指定します。プロジェクトと経歴詳細の双方にリンクが表示されます。
8. 既存の構成図 HTML は `public/architecture/` に置き、`architecture: { src, description }` で詳細ページに埋め込みます。別タブで開くリンクも表示します。

## 構成図の掲載範囲

Resident Portal と AI News Daily は、利用者が提供した Archify HTML を使用しています。公開用コピーから `archify-source-evidence-data` の内容を除き、非公開リポジトリの URL・リビジョン・ソースパスを含めていません。元ファイルは変更していません。図の操作機能とフォントのライセンス表記は保持しています。

## AI News Daily の掲載範囲

GCP 上で動く AI ニュース自動収集・Slack 配信・Claude による日次 HTML 生成の自社内向けシステムです。トップの精選一覧と AI 分野の一覧に掲載しています。社内利用のためアプリ・ソースコードは非公開である旨をカードと詳細ページに明記しています。

- カバー: 利用者が提供した HTML 版の実画面（2026年10月19日号）。左上の会社名は不透明のマスクで覆っています。
- ギャラリー: 同日号の Slack 自動投稿。出典リンクと Web 版への導線を含みます。
- 添付の 1 枚目と 3 枚目は同じ画像のため、公開画像は Web 版と Slack 版の 2 枚です。
- 利用者が提供した Archify 構成図（2026年10月20日）に基づき、Cloud Scheduler → Cloud Run Job → Collector / Analyst / Writer → Slack の日次配信、任意の HTML 生成・GCS 保存・HTML Viewer 配信、Cloud Tasks を経由するスレッド QA を記載しています。
- 構成図の記載に合わせ、07:40 JST の定時起動、並列収集・重複除去、署名検証、event_id による重複排除、OIDC 確認を反映しています。個別のニュース取得先、モデルのバージョン、公開 URL は記載していません。

## Resident Portal の掲載範囲

SALT2 Bootcamp 参加時の開発作品です。アプリ・ソースコードは非公開である旨をカードと詳細ページに明記しています。

実機スクリーンショットを 4 枚使用しています。最初に AI チャットの緊急判断を示し、その下に通常回答と緊急時の分岐を説明してから、管理側の画面を掲載します。

- カバー: AI チャットの緊急表示。利用者がこの会話で添付した実画面から、物件名と電話番号をマスク。質問、AI の緊急表示、問い合わせ先への案内は維持。
- 問い合わせ管理（1280 × 900）: 利用者が指定したブラウザー確認画像 `mcp-chrome-devtools-blob-1791703535383-c2woo3.png` から、物件名・担当者名・質問本文をマスク。
- 月次集計: `屏幕截图 2026-10-12 110857.png`（1738 × 669）。内容は改変せず、サンプルデータの表示と運用成果ではない説明を保持。
- モバイルの連絡先: `mcp-chrome-devtools-blob-1791718951511-tc84tv.png`（360 × 800）。物件名・テナント名・電話番号をマスク。

マスクは不透明の淡い灰緑色で文字部分だけに重ね、UI を描き直していません。公開ファイルはマスクを焼き込んだ PNG のみで、元画像や画像下の隠しテキストを含みません。

元のマニュアル、専用 URL、QR コード、未処理の問い合わせ本文を含む画像はコピーしていません。公開画像を追加するときは、物件名・企業名・問い合わせ本文・リンク・QR コード・資料画像内の情報を確認した上で、上記 `gallery` に追加します。

既存の履歴タイムラインの日時・文言・モバイル表示・経歴詳細は変更していません。
